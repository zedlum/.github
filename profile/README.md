# zedlum

A Debian-compatible OS providing a cooperative, auditable, secure execution
environment for non-deterministic software and a built-in agent.

- [`zed`](https://github.com/zedlum/zed) — dev/bootstrap tool
- [`rfcs`](https://github.com/zedlum/rfcs) — architecture decisions

See `rfcs/Aim.md` and `rfcs/Plan.md` for the full design.
